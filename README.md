# Assignment 4 - Forms and Validation

## Project Description

This project is a Carpet House website created for Web Front-End Development Assignment 4.

The project demonstrates HTML forms, HTML5 validation, Bootstrap styling, and validation feedback.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.3

JavaScript is not used in this project.

## Tasks

### Task 0 - Simple Contact Form
A basic contact form with name, email, message, and submit button.

### Task 1 - HTML5 Validation
A contact form with required fields, email validation, and input length restrictions.

### Task 2 - Bootstrap Form
A contact form styled with Bootstrap components and the Bootstrap Grid system.

### Task 3 - Bootstrap Validation
A contact form with Bootstrap validation classes and feedback messages.

### Task 4 - Registration Form
A responsive registration form with personal information, passwords, gender, hobbies, country selection, and HTML5 validation.

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Use the navigation bar to switch between tasks.

An internet connection is required to load Bootstrap through CDN.

## Notes

- The forms demonstrate client-side validation.
- No backend or database is connected.
- Password fields are validated separately. Password matching is not implemented because JavaScript is not used.
